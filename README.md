# E-commerce Agent OS

A clean rebuild of the previous Master Agent OS, focused only on AI-assisted e-commerce operations.

## First milestone

- Visual AI office
- Product research pipeline
- Agent status and progress
- Product scoring
- Human approval queue

The first milestone uses local demo data. AutoDS, Shopify, persistent storage and live AI jobs will be connected only after the workflow is approved.

## Run locally

```bash
npm install
npm run dev
```
