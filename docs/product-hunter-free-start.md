# Product Hunter: nemokamas pradinis režimas

Šis režimas skirtas pradėti rinkos tyrimą be mokamų reklamų duomenų bazių, mokamų API ir DI API raktų.

## Kas veikia
- Atveriami Google Trends, TikTok Creative Center, Meta Ad Library, Amazon Movers & Shakers ir Reddit vieši šaltiniai.
- Žmogus įrašo kandidatą ir šaltinio nuorodą.
- Naršyklėje skaičiuojama bruto marža pagal produkto savikainą, siuntimą ir pardavimo kainą.
- Kandidatas pažymimas tęsti tyrimą arba turintis atmetimo riziką, kai marža mažesnė nei 60 %, pristatymas viršija 21 dieną arba trūksta esminių skaičių.
- Įrašai saugomi naršyklės localStorage.

## Ribos
- Ši versija pati neieško ir nenuskaito svetainių.
- Ji nevertina pardavimų, tikrųjų reklamos išlaidų ar komentarų automatiškai.
- Vietinis vertinimas yra pirminis filtras, ne galutinė produkto rekomendacija.
- Išvalius naršyklės duomenis arba naudojant kitą įrenginį įrašai nebus pasiekiami.
- Šaltinių nuorodas ir stebėjimo datą peržiūri žmogus.

## Kitas etapas
Pridėti CSV eksportą/importą, tada nemokamas arba oficialiai prieinamas šaltinių jungtis po vieną. DI API ar mokamą duomenų teikėją jungti tik įvertinus tikrą naudą ir kainą.
